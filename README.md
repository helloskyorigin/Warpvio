# Warpvio — Landing Page (V1)

Responsive single-file landing page with no bubble/orb background elements.

## View
Open `index.html` in a browser or deploy the root folder on GitHub Pages / any static host. All page CSS and JavaScript are included in the same HTML file. The Google Fonts stylesheet is optional (system fallbacks apply).

## Features
- Responsive desktop/mobile hero and landing sections
- Website URL input validation
- Windows, Android and macOS multi-selection
- Review modal, mobile menu, scroll reveals and interactive FAQ
- Soft blue/lavender gradients without floating bubbles
- One-time pricing illustrations with no free export

## Still to build
The first page is a frontend prototype. The URL input opens a summary, **not a website scan**. Real compatibility analysis, secure checkout, Android/Windows/macOS build workers, download/recovery, ownership verification, legal/support content and platform signing/distribution are not implemented. Pricing shown is proposed only.
